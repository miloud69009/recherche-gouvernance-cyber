# 🛡️ Recherche : Framework Sémantique pour Politiques de Sécurité Hétérogènes

## 📌 Présentation
Ce dépôt regroupe les travaux de recherche menés sur la gouvernance en cybersécurité et l'interopérabilité des modèles de contrôle d'accès. 

Dans les systèmes d'information modernes, les fusions et évolutions entraînent souvent la cohabitation de politiques de sécurité incohérentes (normes NIST/ISO, modèles RBAC, ABAC, PBAC). L'objectif de cette étude est de proposer une **approche conceptuelle d'un cadre sémantique** permettant de faire cohabiter ces politiques sans conflit, en réconciliant les intentions stratégiques et les configurations techniques.

## 🎯 Architecture Conceptuelle Proposée

Notre recherche a abouti à la proposition d'un framework sémantique structuré en trois couches distinctes :

1. **Couche 1 : Gouvernance & Conception (Stratégie)**
   Définition de l'intention de sécurité (Secure by Design, alignement avec la gestion des risques) indépendamment de toute contrainte technique.
2. **Couche 2 : Structure & Normalisation (Traduction)**
   Alignement sémantique entre les différents langages du SI (flux réseau, rôles annuaire, exigences organisationnelles) vers un format unifié (ex: JSON standardisé).
3. **Couche 3 : Intelligence Sémantique (Exécution)**
   Utilisation d'un moteur d'inférence (basé sur des ontologies OWL et règles SWRL) capable de prendre des décisions d'accès dynamiques et de détecter/résoudre les conflits (ex: approche *deny override*).
